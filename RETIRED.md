# Retired — 2026-10-26

Agent Inboxes is retired. Nate decided on 2026-10-26 to remove the Agent Inbox
from every project: the concept no longer works for how he builds, and it is no
longer needed. Coding work that used to be dispatched through an Inbox thread is
now done directly by Claude or Codex on the Mac mini.

This repository is kept in place for history only. Do not install the CLI,
register agents, poll or watch inboxes, reserve files, or add Inbox steps to any
project. The hosted service, its DNS and any remaining agent credentials are
being shut down separately.
